# ASE Week 5 - GitHub Branching and Merge Conflict

## Aim

To demonstrate GitHub branching, merging, and merge conflict resolution using a simple Python project.

## Project Description

This project contains a simple login program created for the Advanced Software Engineering (ASE) Week 5 laboratory exercise.

## Files

* README.md
* app.py

## Branches Used

* main
* develop
* feature/login
* feature/conflict

## Outcome

This project demonstrates creating branches, merging code changes, and resolving merge conflicts in GitHub.
